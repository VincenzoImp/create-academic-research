# Write Paper Workflow

Manuscript scripts should read `reports/paper/<manuscript_id>/manuscript.yaml`,
`paper-claim-map.csv`, `citation-map.csv`, and `asset-map.csv`.

The manuscript is assembled from an accepted frame, reviewed contribution
packages, analysis paper exports, and the central bibliography at
`sources/bib/references.bib`. Tables, figures, and numeric values should point
to upstream generated files through `asset-map.csv`.

Before a draft is final, run an adversarial review that checks claim support,
citation reconciliation, asset freshness, venue fit, badge evidence, and clean
copy status.
