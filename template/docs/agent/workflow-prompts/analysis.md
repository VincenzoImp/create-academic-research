# Analysis Workflow Prompt

## Purpose

Execute strict contribution-local analyses or experiments with manifest-driven
inputs, generated outputs, reportable tables, figures, and review gates.

## Preflight

Run `npm run workflow:analysis` and inspect the analysis manifest, report,
figure catalog, stats appendix, blocker summary, paper export folder, and
required contribution inputs.

## Required Skills

Use research-data-analysis, research-results-reporting,
publication-figures-tables, citation-claim-audit, and adversarial-peer-review
skills.

## Ledger

Update the analysis manifest, generated data paths, table paths, figure paths,
stats appendix, figure catalog, report, paper export, validation commands, and
review records.

## Review Loop

If strict preflight fails, write only the blocker summary. Otherwise run,
validate, review, fix, and re-review analysis outputs until no data, method,
metric, interpretation, or clean-copy issue remains.

## Handoff

Handoff only generated files and reports that reference canonical data, tables,
figures, scripts, seeds, commands, limitations, and claim IDs.
