# Paper Frame Workflow Prompt

## Purpose

Select a venue-aware paper framing from reviewed contribution packages,
evidence maps, compliance targets, release implications, and audience needs.

## Preflight

Run `npm run workflow:frame` and inspect frame ledger, frame contract, selected
contributions, argument map, evidence map, badge fit, compliance fit, venue fit,
release plan, outline, reviews, and decision.

## Required Skills

Use paper-framing, cs-venue-strategy, adversarial-peer-review, and
badge-compliance-profiles skills.

## Ledger

Update `paper_frames/frame-ledger.csv`, selected contribution map, argument map,
evidence map, venue fit, badge fit, compliance fit, release plan, outline,
reviews, and decision.

## Review Loop

Evaluate each frame for novelty, contribution coherence, evidence sufficiency,
venue fit, badge feasibility, release constraints, and narrative risk. Iterate
until accepted, rejected, or held with a defensible decision.

## Handoff

Handoff only accepted frames to manuscript and release workflows.
