# Manuscript Workflow Prompt

## Purpose

Assemble a paper manuscript from an accepted frame, reviewed contribution
reports, analysis paper exports, central BibTeX, claim maps, citation maps, and
asset maps.

## Preflight

Run `npm run workflow:manuscript` and inspect manuscript ledger, manifest,
LaTeX main file, sections, paper claim map, citation map, asset map, frame
decision, contribution reports, release ledger, and reviews.

## Required Skills

Use paper-writing, citation-claim-audit, publication-figures-tables,
adversarial-peer-review, and badge-compliance-profiles skills.

## Ledger

Update `reports/paper/manuscript-ledger.csv`, manuscript manifest, paper claim
map, citation map, asset map, LaTeX sections, reviews, and archive.

## Review Loop

Write section by section. Review each section for unsupported claims, stale
citations, stale tables, stale figures, missing caveats, venue mismatch, and
draft residue. Fix and re-review until clean.

## Handoff

Handoff only manuscripts whose final review passes claim support, citation
reconciliation, asset freshness, venue fit, and clean-copy gates.
