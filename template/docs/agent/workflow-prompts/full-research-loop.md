# Full Research Loop Prompt

## Purpose

Run the whole project as a controlled academic workflow rather than a sequence
of free-form drafts.

## Ordered Workflow

source ingestion -> SOTA -> survey -> research agenda -> contribution -> analysis -> paper framing -> paper release -> manuscript -> submission -> response

## Preflight

At each stage, run the matching `npm run workflow:<stage>` command, inspect the
reported prompt path, required files, skills, ledgers, and blocking gaps, then
follow the stage prompt.

## Required Skills

Install and use the academic research skills for each stage, plus Superpowers
skills for implementation, testing, review, and verification discipline.

## Ledger

No stage advances without updating its ledger, manifest, claim map, evidence
map, asset map, citation map, or review record as applicable.

## Review Loop

Every production artifact follows plan, partial draft or execution, adversarial
review, fix, re-review, and final clean-copy gate. Iterate until no blocking
issue remains.

## Handoff

Advance only by clean reviewed handoff. Do not carry stale files, unsupported
claims, draft residue, legacy state, or contradictory conclusions forward.
