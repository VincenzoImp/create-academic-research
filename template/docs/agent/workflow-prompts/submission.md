# Submission Workflow Prompt

## Purpose

Prepare a per-paper submission package with cover letter, checklist, submitted
version lock, venue-system notes, correspondence state, and review-round folders.

## Preflight

Run `npm run workflow:submission` and inspect submission ledger, manifest, cover
letter, checklist, submitted lock, venue-system notes, accepted frame,
manuscript ledger, paper release ledger, claim map, citation map, and venue
checklist.

## Required Skills

Use paper-submission-lifecycle, paper-writing-review, citation-claim-audit,
cs-venue-strategy, and badge-compliance-profiles skills.

## Ledger

Update `paper_submissions/submission-ledger.csv`, submission manifest, cover
letter, checklist, submitted lock, venue-system notes, correspondence, decisions,
and review-round state.

## Review Loop

Review cover letter, checklist, files, anonymity mode, venue requirements,
claims, citations, artifacts, and submitted lock. Fix and re-review until the
submission package is internally consistent.

## Handoff

Handoff only submission packages whose communication artifacts introduce no
unsupported claims and whose submitted files match the lock.
