# Response Workflow Prompt

## Purpose

Manage reviewer comments, concern maps, linked new work, manuscript changes,
response letters, rebuttals, revision plans, and camera-ready state.

## Preflight

Run `npm run workflow:response` and inspect decision letter, reviewer comments,
concern map, linked-work map, manuscript-change map, response strategy, revision
plan, response letter, rebuttal, submission ledger, manuscript ledger, and
contribution ledger.

## Required Skills

Use rebuttal-revision-strategy, paper-submission-lifecycle,
citation-claim-audit, paper-writing-review, contribution-package, and
research-data-analysis skills.

## Ledger

Update concern map, linked-work map, manuscript-change map, response strategy,
revision plan, response letter, rebuttal, reviews, and submission ledger.

## Review Loop

Split comments into atomic concerns. For each concern, decide whether it needs
clarification, manuscript change, citation work, analysis, artifact work, or a
new contribution. Fix, verify, and re-review until no response gap remains.

## Handoff

Handoff only response packages whose promised changes, linked work, manuscript
locations, and evidence anchors have passed review.
